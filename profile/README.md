# OpenMuscle

Open-source, modular prosthetic sensing. OpenMuscle uses pressure and muscle
activity to drive machine-learning-based control, with open hardware, open
firmware, and an open data pipeline.

## Start here

| I want to... | Go to |
|--------------|-------|
| Understand the project | [OpenMuscle-Hub](https://github.com/Open-Muscle/OpenMuscle-Hub) or [openmuscle.org](https://openmuscle.org) |
| Build the 60-sensor wearable | [OpenMuscle-FlexGrid](https://github.com/Open-Muscle/OpenMuscle-FlexGrid) + [FlexGridV3-Firmware](https://github.com/Open-Muscle/FlexGridV3-Firmware) |
| Use the gesture labeler wand | [OpenMuscle-LASK5](https://github.com/Open-Muscle/OpenMuscle-LASK5) |

| Explore AR / XR | [OpenMuscle-AR](https://github.com/Open-Muscle/OpenMuscle-AR) |
