# Contributors

OpenMuscle is built by a community. This file records contributions that do not
show up automatically in a repo's GitHub contributors graph, especially
**idea-only** contributions: a suggestion, a design direction, or a bug report
that someone else then implemented.

If you contributed an idea that shipped and you never pushed a commit, you belong
here. Add yourself in a pull request, or ask a maintainer to add you. People who
merged pull requests are also credited automatically in each repo's contributors
graph and in commit co-author trailers.

## Emoji key

Contribution types follow the [All Contributors](https://allcontributors.org/docs/en/emoji-key) emoji key:

- 💡 ideas and planning
- 🐛 bug reports
- 📖 documentation
- 💻 code
- 🎨 design
- 🔧 tooling
